# Reference data and third-party tools

The repository provides a versioned reference manifest and checksum-verifying
fetcher. Full human genomes and GTFs stay at their official source; downloaded
copies stay outside Git. This makes provenance visible and avoids distributing
stale or mismatched copies. No third-party program source is vendored here.

## GENCODE release 48 / GRCh38.p14

The file names and MD5 checksums in `gencode_v48.json` were retrieved from the
[official release](https://www.gencodegenes.org/human/release_48.html) and its
[MD5SUMS file](https://ftp.ebi.ac.uk/pub/databases/gencode/Gencode_human/release_48/MD5SUMS)
on 2026-09-27. MD5 checks transport integrity against the upstream manifest;
it is not a cryptographic authenticity guarantee. Downloads use HTTPS.

```bash
python3 references/DownloadReferences.py --list
# Complete annotation + genome + matching ALL transcript set (large downloads):
python3 references/DownloadReferences.py --id annotation_all --id genome_all --id transcripts_all
# OR a primary-assembly genome and matching primary annotation:
python3 references/DownloadReferences.py --id annotation_primary --id genome_primary
```

Files go to ignored `references/downloads/`. Existing matching files are reused;
mismatched files cause an error and are not overwritten. Interrupted or failed
new downloads leave no final file. Downloads are not automatic during analysis.
Keep the manifest with an analysis and record local checksums in its run output.
Use `gzip -dk FILE.gz` to retain a compressed original and create an uncompressed
GTF/FASTA for the external callers (budget disk space for both).

**Match what was used for alignment and quantification.** Do not change an existing
study's reference halfway through analysis. The user's `gencode.v48.annotation.gtf`
is the **CHR** annotation, not the ALL or PRI annotation. GENCODE's transcript FASTA
covers **ALL** regions. For a Salmon index built from this complete transcript set,
use the ALL GTF; alternatively create a deliberately filtered transcript FASTA
matching the chosen GTF and rebuild the index. Merely changing an annotation path
after quantification does not resolve an incompatible index.

A genome FASTA and a transcript FASTA are different inputs. IsoformSwitchAnalysis
needs spliced transcript sequences matching Salmon and the GTF; Arriba needs the
genomic sequence matching its STAR alignment. Preserve versioned transcript IDs.
For GENCODE pipe-delimited FASTA/Salmon identifiers, use the documented `strip_pipe`
option; ambiguous ID collisions fail. Keep Salmon index construction options,
Salmon version, and alignment/quantification command logs with the study.

A reference alone does not configure every caller: rMATS also needs library/read
length settings; Arriba needs its assembly-matched blacklist and appropriate STAR
chimeric alignment settings. These are deliberately not guessed.

## What belongs on GitHub?

Reusing and forking published tools is routine **when the license permits it**.
Keep the original license, required notices and authorship; cite the paper and
mark your changes. A citation alone is not permission to redistribute code or
data. Publicly readable material with no license is not automatically reusable.
For full terms, consult the specific tool or data provider; data and software
can have different licenses. See [GitHub's licensing guide](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)
and [EMBL-EBI terms](https://www.ebi.ac.uk/about/terms-of-use/).

Prefer links, package installation instructions and pinned manifests for external
dependencies. Use a fork when you actually maintain modifications to another
project. Regular GitHub repositories block individual files over 100 MiB;
[GitHub's large-file guidance](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github)
explains alternatives. This project does not configure paid Git LFS storage.

The tiny GTF and transcript FASTA in `examples/isoform_switch/` are generated
synthetic test data, not redistributed human sequences or production references.
The BAM fixtures are generated by `tests/make_fixtures.R`.

## Upstream software and citations

Install software from its official project rather than copying executables here:

* [DESeq2](https://bioconductor.org/packages/DESeq2/) and [edgeR](https://bioconductor.org/packages/edgeR/)
* [Rsubread / featureCounts](https://bioconductor.org/packages/Rsubread/)
* [rMATS-turbo](https://github.com/Xinglab/rmats-turbo)
* [StringTie](https://ccb.jhu.edu/software/stringtie/) and [GffCompare](https://ccb.jhu.edu/software/stringtie/gffcompare.shtml)
* [Arriba](https://arriba.readthedocs.io/)
* [Salmon](https://salmon.readthedocs.io/), [tximport](https://bioconductor.org/packages/tximport/),
  [DEXSeq](https://bioconductor.org/packages/DEXSeq/) and [IsoformSwitchAnalyzeR](https://bioconductor.org/packages/IsoformSwitchAnalyzeR/)

Use each package's `citation("PackageName")` and the reference provider's release
citation in publications. The wrapper does not replace acknowledgment of these
methods or transfer their licenses to you.
